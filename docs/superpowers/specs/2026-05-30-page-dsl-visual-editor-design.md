# 页面 DSL 可视化编辑器设计

> **Status:** ✅ Completed — fully implemented in `frontend/apps/admin/src/app/(dashboard)/pages/[id]/edit/`

> 日期：2026-05-30
> 状态：已批准
> 范围：整体优化 pages 模块，新增全屏拖拽编辑器 + 实时预览

## 背景

当前 admin pages 模块（`pages/page.tsx`，~1087 行单文件）存在以下问题：
- DSL 编辑器是 Drawer 内的 TextArea，用户体验差
- 模块排序只有上下箭头按钮，无法直观拖拽
- 没有实时预览，管理员无法看到消费者 H5 的实际效果
- 所有组件内联在一个文件中，维护困难

## 目标

1. 拖拽排序：用 dnd-kit 实现模块拖拽重排
2. 实时预览：iframe 嵌入真实 H5 页面，DSL 变更实时反映
3. 整体优化：模板列表、版本管理、DSL 编辑器各自独立

## 方案选择

**布局方案**：左右分屏（左侧编辑区 + 右侧手机预览 iframe）

选择理由：
- 编辑区和预览区视觉平衡，适合宽屏
- 模块列表可直接拖拽，操作直觉
- 实现复杂度适中

**入口方式**：全屏独立页面（`/pages/[id]/edit`）

选择理由：
- 浏览器前进/后退天然支持导航
- 左右分屏可以利用全部视口空间
- 组件可以按文件拆分

**拖拽库**：dnd-kit（~40KB，专注拖拽排序，API 简洁）

**预览方式**：iframe 嵌入真实 H5（`/preview` 路由），通过 postMessage 通信

## 路由与页面结构

| 路由 | 文件 | 说明 |
|------|------|------|
| `/pages` | `pages/page.tsx` | 模板列表（保留 Table，优化操作按钮） |
| `/pages/[id]` | `pages/[id]/page.tsx` | 版本管理页（从 Modal 改为独立页面） |
| `/pages/[id]/edit` | `pages/[id]/edit/page.tsx` | 全屏 DSL 编辑器（新建） |

### 左侧编辑区

- 顶部 Tab 切换：模块排序 / 活动期配置 / JSON 编辑
- 模块排序列表用 dnd-kit 实现拖拽
- 点击模块行展开/收起属性配置面板（inline accordion）
- 底部"添加模块"按钮

### 右侧预览区

- iframe 嵌入 H5 预览页面
- DSL 变更时通过 postMessage 实时推送配置到 iframe（防抖 300ms）
- 设备切换（iPhone 15 / iPhone SE / 桌面）
- 缩放控制

## 拖拽交互设计

- **拖拽手柄**：每个模块左侧的 `≡` 图标
- **拖拽反馈**：拖起时模块半透明，放置位置显示蓝色指示线
- **禁用模块**：灰色显示但保留在列表中，可拖拽排序
- **点击展开**：点击模块行展开属性配置表单
- **展开的模块**：拖拽时自动收起

## 实时预览机制

```
编辑器 (Admin :3000)                H5 预览服务 (:3001)
┌─────────────────┐                ┌─────────────────┐
│  DSL 变更        │  postMessage   │  /preview 页面   │
│  ───────────────→│──────────────→│                  │
│                  │                │  接收 DSL config │
│                  │                │  渲染模块组件     │
└─────────────────┘                └─────────────────┘
```

- H5 端新增 `/preview` 路由，监听 `postMessage` 接收 DSL 配置
- Admin 端 iframe 加载 `{H5_URL}/preview`
- DSL 每次变更（防抖 300ms）通过 `postMessage` 推送
- H5 预览页面用现有消费者端组件渲染模块

## 文件结构

```
apps/admin/src/app/(dashboard)/pages/
  page.tsx                           # 模板列表（优化版）
  [id]/
    page.tsx                         # 版本管理页
    edit/
      page.tsx                       # 全屏编辑器主页面
      components/
        ModuleList.tsx               # 拖拽模块列表
        ModuleItem.tsx               # 单个模块（拖拽手柄+开关+属性表单）
        ModuleConfigForms.tsx        # 各模块类型的配置表单
        RoutingConfig.tsx            # 活动期路由配置
        PreviewPanel.tsx             # iframe 预览面板
        EditorHeader.tsx             # 顶部导航栏（返回、保存、发布）
```

`lib/page-dsl.ts` 保持不变，继续作为 DSL 类型定义和验证工具库。
