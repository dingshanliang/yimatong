# 可访问性基线

> 目标等级 **WCAG 2.2 AA**。基线必须可检查：构建期自动校验 + 走查清单。

## 对比度

| 内容                             | 最低比值                                        |
| -------------------------------- | ----------------------------------------------- |
| 正文文本                         | 4.5:1                                           |
| 大字（≥18px 或 14px 粗体）/ 图标 | 3:1                                             |
| H5 租户主色（对白底）            | 3:1（服务端校验）                               |
| 按钮文字（对品牌色）             | 4.5:1（`pickAccessibleForeground` 自动选黑/白） |

- 关键文本/背景组合登记在 `accessibilityPairs`（`lib/themes.ts`），node:test 逐对校验，**FAIL 即构建失败**
- 预览页"可访问性检查"区展示每对实际比值

## 四项交互基线

1. **焦点可见**：统一 `focus.ring` 语义色 2px 外描边 + 2px offset（`theme.css` 全局 `:focus-visible` 已实现）；**禁止 `outline: none`**（除非提供等效替代）
2. **触控目标**：H5 ≥ 44px，Admin ≥ 32px，主 CTA 48px
3. **色彩不单独传信**：状态必须双编码（如表格状态列 = 文字 + 色彩，不用纯彩色圆点）
4. **字号下限**：Admin 正文/表格 ≥ 12px；H5 正文 ≥ 14px

## 新页面走查清单

提 PR 前逐项勾选：

- [ ] 文本/背景对比度满足上表（语义 token 组合已验证；自绘部分自查）
- [ ] 键盘 Tab 顺序合理，焦点态全程可见
- [ ] 所有按钮/链接触控目标达标
- [ ] 状态信息不只靠颜色（有文字或图标）
- [ ] 无字号低于下限的文本
- [ ] 图片/图标有替代文本或 `aria-hidden`
- [ ] 表单字段有 `label`，校验错误就地提示且可被读屏
- [ ] light/dark 双主题下均走查过（Admin/Platform 页面）
