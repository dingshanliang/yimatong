# H5 租户品牌定制规范

> H5 是消费者的品牌触点：一码通提供默认主题，租户在**受控槽位**内表达品牌。开放度以"观感下限不翻车"为边界。

## 七个定制槽位

| 槽位           | 说明                            | 约束                                                          |
| -------------- | ------------------------------- | ------------------------------------------------------------- |
| Logo           | 租户品牌 Logo，展示在页面头部   | `logo_url`，复用 `/files/upload` 上传后的公开 URL（ADR-0001） |
| 品牌主色       | 按钮、强调、徽标的品牌色        | 自由 hex + 服务端校验（见下）                                 |
| 按钮/圆角风格  | 三档预设（贴合 token 圆角刻度） | 只能从预设档选择，不开放数值                                  |
| 页面背景       | 预设浅色背景组                  | 只能从预设组选择                                              |
| 隐藏一码通背书 | 隐藏"一码通提供技术支持"        | 布尔开关（对应 `hide_yimatong_brand`）                        |
| 客服电话       | H5 错误/等待页"电话咨询"入口    | `support_phone`，宽松电话格式校验；未配置回退平台默认         |
| 企微客服链接   | H5 错误/等待页"在线客服"入口    | `support_wecom_url`，https 公开链接校验；未配置不渲染链接     |

> Logo 存储决策见 [ADR-0001](../../../adr/0001-brand-profile-includes-logo-url.md)：并入 `brand_profile.logo_url`，不新建通用 asset 库。H5 渲染时租户配置优先于产品品牌 Logo。

**不开放**：字体、feedback 色系、焦点色、正文/错误文字色、自定义 CSS。

## 品牌主色约束

- 保存时**服务端校验**：与白底对比度 ≥ 3:1，饱和度/亮度在安全域内；不合格拒绝并提示
- 按钮文字色由 `pickAccessibleForeground` 自动选黑/白（对比度 ≥ 4.5:1）
- hover/active/浅背景等衍生色由锚点**算法派生**，租户不逐项配置

## 三层回退

```
页面/活动 DSL 覆盖（brand_theme）
  → 租户级 brand_profile 默认
  → 一码通默认主题（方向 A 品牌绿）
```

- 活动营销场景（如新年红）在页面/活动 DSL 层覆盖主色，不污染租户默认
- 未配置的槽位沿回退链取默认值

## 落地形态：CSS 变量注入

- 解析后的槽位值注入为 H5 根节点 CSS 变量（`--color-brand-*` 等），组件只消费变量，不做 JS 样式计算
- 与 design-tokens 的 `--ymt-*` 变量同构；租户主色覆盖 `--ymt-color-brand-*` 与 `--ymt-color-action-*` 系列
- 现有 DSL 字段 `primary_color` / `logo_asset_id` / `hide_yimatong_brand` 并入槽位体系，**DSL 向后兼容**

## H5 通用约束

- 仅浅色主题，不做深色
- 基准字号 16，正文下限 14
- 触控目标 ≥ 44px（`theme.css` 已全局兜底）
- 移除 `maximumScale` viewport 限制，允许用户缩放
