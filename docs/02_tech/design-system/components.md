# 组件使用规范（Admin / Platform）

> 本文是 antd 6 组件的**使用约定**，不建共享组件库。H5 消费端走 DSL 模块体系，另见 [h5-branding.md](h5-branding.md)。

## 页面骨架

### 列表页（四段式）

```
PageHeader（标题 + 主操作按钮）
  → 筛选区（常用筛选外露，高级筛选默认收起）
  → 工具栏（批量操作 / 导出）
  → 表格 + 分页
```

- 页面边距 24，卡片/段落间距 16（4px 基数刻度）
- **排序契约：新增/修改的记录排在列表第一位**

### 详情页

头部（标题 + 状态 + 主操作）→ Tab 或描述列表组织内容。

## 组件选型硬规则

| 场景          | 规则                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------- |
| 数据记录展示  | 一律 `Table`；`List`/`Card` 网格仅用于"对象即入口"场景（如页面装修模板、应用市场式入口） |
| 新建/编辑表单 | 字段 ≤ 6 用 `Modal`；> 6 用 `Drawer`；跨步骤/长流程用独立页                              |
| 数值展示      | 表格数字列右对齐 + `tabular-nums`；金额/码量用千分位                                     |
| 日期时间      | 统一 `DatePicker`/格式化工具，禁止手拼字符串                                             |

## 反馈分级

| 级别   | 场景                                                         | 组件                             |
| ------ | ------------------------------------------------------------ | -------------------------------- |
| 轻反馈 | 保存成功、复制成功等轻操作                                   | `message`（2s 自动消失）         |
| 重反馈 | 需要用户知晓的结果、含后续动作（如"导出完成，点击下载"）     | `notification`                   |
| 错误   | 表单校验错误**就地红字**，不弹窗；接口失败在操作位置附近展示 | Form 校验 / `notification.error` |

### 危险操作确认

- 不可逆操作（删除、下线、作废）一律 `Modal` 二次确认：**红色按钮 + 对象名称 + 后果说明**（如"删除后 50,000 个码将不可解析"）
- 批量危险操作需输入确认词（对象名或"确认删除"）
- 可逆的状态切换（启用/停用）用 `Popconfirm` 即可

## 边角状态

| 状态     | 约定                                                                |
| -------- | ------------------------------------------------------------------- |
| 空状态   | `Empty` + 一句引导语 + 主操作按钮（如"还没有批次，新建第一个批次"） |
| 表格加载 | Table 内置 `loading`，不用整页 Spin                                 |
| 整页加载 | `Spin` 居中                                                         |
| 错误页   | `Result` 组件（403/404/500）                                        |
| 插画风格 | 待图标/插画体系票确定后补充，当前用 antd 默认                       |

## 双主题

- Admin / Platform 均支持 light/dark，主题切换入口在头部
- 自绘样式（非 antd 部分）必须消费语义 CSS 变量（`var(--ymt-color-*)` 或 admin 的 `--admin-*` 映射层），禁止硬编码 hex
- 图表（@ant-design/charts）色板从 `themes.dark` 派生，见 `src/lib/theme-provider.tsx`
