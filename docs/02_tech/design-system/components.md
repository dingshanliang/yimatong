# 组件使用规范（Admin / Platform）

> 本文是 antd 6 组件的**使用约定**，不建共享组件库。H5 消费端走 DSL 模块体系，另见 [h5-branding.md](h5-branding.md)。

## 页面骨架

### 列表页（四段式）

```
PageHeader（标题 + 主操作按钮）
  → 筛选区（常用筛选外露，高级筛选默认收起）
  → 工具栏（批量操作 / 导出）
  → 表格 + 分页
```

- 页面边距 24，卡片/段落间距 16（4px 基数刻度）
- **排序契约：新增/修改的记录排在列表第一位**

### 详情页

头部（标题 + 状态 + 主操作）→ Tab 或描述列表组织内容。

## 组件选型硬规则

| 场景          | 规则                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------- |
| 数据记录展示  | 一律 `Table`；`List`/`Card` 网格仅用于"对象即入口"场景（如页面装修模板、应用市场式入口） |
| 新建/编辑表单 | 字段 ≤ 6 用 `Modal`；> 6 用 `Drawer`；跨步骤/长流程用独立页                              |
| 数值展示      | 表格数字列右对齐 + `tabular-nums`；金额/码量用千分位                                     |
| 日期时间      | 统一 `DatePicker`/格式化工具，禁止手拼字符串                                             |

## 反馈分级

| 级别   | 场景                                                         | 组件                             |
| ------ | ------------------------------------------------------------ | -------------------------------- |
| 轻反馈 | 保存成功、复制成功等轻操作                                   | `message`（2s 自动消失）         |
| 重反馈 | 需要用户知晓的结果、含后续动作（如"导出完成，点击下载"）     | `notification`                   |
| 错误   | 表单校验错误**就地红字**，不弹窗；接口失败在操作位置附近展示 | Form 校验 / `notification.error` |

### 危险操作确认

- 不可逆操作（删除、下线、作废）一律 `Modal` 二次确认：**红色按钮 + 对象名称 + 后果说明**（如"删除后 50,000 个码将不可解析"）
- 批量危险操作需输入确认词（对象名或"确认删除"）
- 可逆的状态切换（启用/停用）用 `Popconfirm` 即可

## 边角状态

| 状态     | 约定                                                                                     |
| -------- | ---------------------------------------------------------------------------------------- |
| 空状态   | **V2 品牌容器**（见下节）+ 一句引导语 + 一个实心主按钮（如"还没有批次，新建第一个批次"） |
| 表格加载 | Table 内置 `loading`，不用整页 Spin                                                      |
| 整页加载 | `Spin` 居中                                                                              |
| 错误页   | `Result` 组件（403/404/500），视觉语言与空状态一致，仅换图标语义与反馈色                 |
| 插画     | **不用叙事插画**（轻量路线），空/加载/错误三态共用同一视觉语言                           |

## 空状态规范（V2 品牌容器）

经原型对比选定（原型留档：`prototype/empty-states` 分支 `preview/prototype-empty-states.html`）。三态共用结构：**图标容器 → 标题 → 描述 → 主动作**，居中、最大宽度约 320px。

- **图标容器**：`bg-brand-subtle` 大圆角（radius 18）容器约 80×80，内嵌 34px 线性图标、`brand-primary` 色；H5 可按比例放大
- **标题** 15px / 500 / `text-primary`；**描述** 13px / 行高 1.6 / `text-secondary`
- **主动作**：实心主按钮（`action-primary`），有且仅有一个

## 图标体系

- **选型**：Admin/Platform 用 `@ant-design/icons`（antd 组件内部同库）；H5 用 `lucide-react`
- **风格**：线性一套——后台限 Outlined 变体（禁 Filled/TwoTone 混用），lucide 天然线性
- **颜色**：一律 `currentColor`，由语义 token 着色，禁硬编码
- **尺寸档位**：后台 14/16；H5 16/20/24
- **禁止**新增手写内联 SVG（品牌 Logo 除外）；存量 H5 内联 SVG 随迁移批 0 替换为 lucide
- 高频语义（新增/编辑/删除/上传等）两端映射表：antd `PlusOutlined` ↔ lucide `Plus`、`EditOutlined` ↔ `Pencil`、`DeleteOutlined` ↔ `Trash2`、`UploadOutlined` ↔ `Upload`，以此类推，保持语义一致

## 双主题

- Admin / Platform 均支持 light/dark，主题切换入口在头部
- 自绘样式（非 antd 部分）必须消费语义 CSS 变量（`var(--ymt-color-*)` 或 admin 的 `--admin-*` 映射层），禁止硬编码 hex
- 图表（@ant-design/charts）色板从 `themes.dark` 派生，见 `src/lib/theme-provider.tsx`
