# 面向研发 / AI 编程工具的任务拆解

> ⚠️ **本文档已归档**（2026-06-03）
> 阶段一（EPIC 01-08）已全部完成，阶段二（EPIC 09-16）大部分完成。
> 任务跟踪已迁移至 beads 和 git commits，本文档仅作历史参考。
> 当前开发进度参见 CLAUDE.md 顶部的项目概述。

## 1. 开发说明

本文件面向 Claude Code、Codex 或研发团队拆解任务。建议先实现阶段一核心闭环，再逐步扩展阶段二和阶段三能力。

## 2. 阶段一 Epic

### EPIC-01 多租户与认证权限

目标：实现 SaaS 基础底座。

任务：

- 建立 Tenant、Organization、Account、Role、Permission 数据模型。
- 实现登录、退出、当前用户接口。
- 实现 tenant scope 中间件。
- 实现基础 RBAC。
- 建立平台后台开通租户接口。
- 支持套餐、到期时间、码量、扫码量额度字段。

验收：不同租户数据隔离；品牌方不能访问其他客户数据；平台管理员可创建租户。

### EPIC-02 产品资料库

任务：

- 产品、SKU、批次 CRUD。
- 检测报告、资质证书、素材上传。
- 文件对象存储封装。
- 批量导入产品和批次。
- 产品资料可被页面模板复用。

验收：可为一个产品配置规格、批次、产地、生产日期、检测报告和图片。

### EPIC-03 码管理

任务：

- 码批次创建。
- 生成 public_id 和 code_url。
- 支持批次码和一物一码。
- 码包导出。
- 码状态：generated、exported、pending_activation、active、voided。
- 激活/作废接口。
- 既有码批量导入。

验收：生成 1000 个码，导出后激活，任意一个码扫码可进入 H5 页面。

### EPIC-04 码解析服务

任务：

- 实现 `/c/{public_id}` 短链入口。
- 校验码是否存在、激活、作废。
- 写入 scan.opened / scan.resolved 事件。
- 判断首扫/重扫。
- 解析扫码环境和 UTM 参数。
- 返回页面版本或异常页面。

验收：微信/浏览器访问短链可打开页面；重复扫码次数累计。

### EPIC-05 页面引擎

任务：

- 页面模板表、页面版本表。
- 模块化配置 DSL。
- 草稿、预览、发布、下线。
- 行业模板初始化：食品、农产品、礼盒、区域品牌。
- H5 渲染产品卡、溯源、检测报告、优惠券、私域按钮、活动规则。

验收：运营人员可配置一个产品扫码页，发布后消费者扫码可看到最新版本。

### EPIC-06 活动与权益基础

任务：

- 活动 CRUD。
- 权益 CRUD：平台券、外部链接、私域权益、表单权益。
- 权益库存、领取限制。
- 领取接口和幂等控制。
- 留资表单提交。
- 私域/电商跳转记录。

验收：用户扫码后可领券、提交表单、点击企微/公众号/小程序/店铺入口，后台可查看记录。

### EPIC-07 埋点与基础看板

任务：

- 事件表。
- 基础事件写入 SDK/API。
- 经营看板：扫码、独立用户、领券、留资、私域点击、外部跳转。
- 活动看板：漏斗、活动对比。
- 数据导出。

验收：测试活动产生的数据能在看板看到，并能导出。

### EPIC-08 代运营工作台基础版

任务：

- 客户列表。
- 客户开通状态、套餐、到期时间。
- 初始化进度。
- 待办任务：资料待收集、页面待发布、码待激活、活动待上线。
- 上线检查清单。

验收：代运营人员能看到客户从开通到上线的进度。

## 5. 通用 Definition of Done

- API 有鉴权、权限和 tenant scope。
- 有单元测试或至少有接口测试。
- 有基础错误处理和日志。
- 写操作有操作日志。
- 涉及权益发放有幂等控制。
- 涉及个人信息有授权和脱敏。
- 涉及页面发布有版本记录。
- 涉及导出有审计记录。
