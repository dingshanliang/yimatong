# 交付实施手册

## 1. 实施目标

让客户从“开通一码通账号”到“第一个包装扫码活动上线”形成标准化交付流程，减少对单个专家的依赖。

## 2. 实施阶段

### 阶段 1：需求确认

确认内容：

- 客户类型：品牌方、区域品牌、协会、渠道商。
- 产品品类：茶叶、大米、水果、调味品、预制菜、礼盒等。
- 码策略：批次码、一物一码、外码/内码双码。
- 包装状态：新包装、旧包装库存、已有码、未有码。
- 承接路径：企微、公众号、小程序、电商店铺、表单。
- 权益策略：优惠券、积分、礼品、抽奖、私域福利。
- 是否涉及经销商/区域/门店/导购。

### 阶段 2：资料收集

资料清单：

- 品牌 Logo、品牌介绍、联系方式。
- 产品名称、规格、图片、视频。
- 产地、批次、生产日期、保质期。
- 检测报告、资质证书、认证材料。
- 企微二维码、公众号、小程序路径、店铺链接。
- 活动规则、优惠券信息、权益库存。
- 经销商/区域/门店数据。
- 既有码样例、旧链接、旧系统信息。

### 阶段 3：页面与活动配置

- 选择行业模板。
- 配置轻量溯源模块。
- 配置检测报告和资质证书。
- 配置优惠券/权益/积分。
- 配置企微、公众号、小程序、电商跳转。
- 配置活动规则、隐私政策、授权说明。
- 配置埋点和渠道参数。

### 阶段 4：码落地方案

按客户情况选择：

| 情况 | 方案 |
|---|---|
| 小批量试点 | 批量二维码标签 |
| 新包装大批量 | 可变数据印刷 |
| 自动化产线 | 产线喷码/赋码 |
| 旧包装已有二维码 | 域名接管/中转跳转/批量导入 |
| 高价值礼盒 | 外码 + 内码双码 |
| 区域品牌 | 统一模板 + 成员企业码段 |

### 阶段 5：上线检查

- 码能否正常打开。
- 页面内容是否正确。
- 手机相机、微信、支付宝扫码体验是否可用。
- 领券、留资、加微、跳转是否可用。
- 活动规则和隐私授权是否展示。
- 数据看板是否记录扫码和转化。
- 异常码和重复扫码是否有提示。
- 客户确认发布。

### 阶段 6：复盘

建议复盘周期：上线后第 7 天、第 14 天、第 30 天。

复盘内容：

- 扫码量、扫码人数。
- 页面转化率。
- 领券率、留资率、加私域率、跳转率。
- 哪些产品/渠道/区域表现好。
- 是否存在异常扫码或跨区扫码。
- 下轮活动建议。
- 是否需要增购码量、扫码量或服务包。

## 3. 交付边界

一码通负责：

- 系统配置。
- 码包生成。
- 标签文件制作建议。
- 可变印刷/喷码/贴标对接支持。
- 页面和活动配置。
- 数据看板和复盘。

一码通不直接承担：

- 印刷厂生产质量责任。
- 标签实际粘贴执行。
- 电商平台规则变更责任。
- 客户私域客服实际成交承诺。
- 现金红包税务和财务结算，除非另有定制协议。
