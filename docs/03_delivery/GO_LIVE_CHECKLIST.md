# 上线验收清单

## 1. 租户与权限

- [ ] 租户已开通。
- [ ] 套餐、到期时间、码量、扫码量已配置。
- [ ] 品牌管理员账号已创建。
- [ ] 代运营人员已被授权。
- [ ] 权限范围已确认。

## 2. 产品资料

- [ ] 品牌 Logo、名称、联系方式正确。
- [ ] 产品名称、规格、图片正确。
- [ ] 批次、生产日期、保质期正确。
- [ ] 检测报告已上传并可查看。
- [ ] 资质证书已上传并可查看。
- [ ] 中英文资料如需展示已配置。

## 3. 码管理

- [ ] 码策略已确认：批次码/一物一码/双码。
- [ ] 码批次已创建。
- [ ] 码包已导出或既有码已导入。
- [ ] 印刷/贴标/喷码方案已确认。
- [ ] 码段已绑定产品、批次、活动。
- [ ] 码段已激活。
- [ ] 作废码、冻结码不会打开正常页面。

## 4. H5 页面

- [ ] 页面模板正确。
- [ ] 首屏品牌和产品信息正确。
- [ ] 溯源信息正确。
- [ ] 检测报告和证书可打开。
- [ ] 优惠券/权益展示正确。
- [ ] 企微/公众号/小程序/电商入口正确。
- [ ] 活动规则展示正确。
- [ ] 隐私政策和授权说明展示正确。
- [ ] 页面可预览、发布、下线。

## 5. 扫码体验

- [ ] 微信扫一扫可打开。
- [ ] 手机相机可打开。
- [ ] 支付宝扫一扫可打开。
- [ ] 页面加载速度可接受。
- [ ] 首扫提示正确。
- [ ] 重复扫码提示正确。
- [ ] 查无此码/作废/冻结提示正确。

## 6. 活动与权益

- [ ] 活动开始和结束时间正确。
- [ ] 权益库存正确。
- [ ] 领取限制正确。
- [ ] 领券成功记录正确。
- [ ] 外部链接或券码池可用。
- [ ] 留资表单字段和授权正确。
- [ ] 线下核销如有已测试。

## 7. 数据看板

- [ ] 扫码数据记录正确。
- [ ] 页面浏览记录正确。
- [ ] 领券、留资、私域点击、商城跳转记录正确。
- [ ] 活动漏斗显示正确。
- [ ] 数据导出权限正确。
- [ ] 异常扫码预警可触发。

## 8. 客户确认

- [ ] 客户已确认页面内容。
- [ ] 客户已确认活动规则。
- [ ] 客户已确认码落地方案。
- [ ] 客户已确认上线时间。
- [ ] 上线后 7/14/30 天复盘已安排。
