# 代运营与客户成功手册

## 1. 代运营工作台目标

一码通采用 SaaS + 代运营配置并行。代运营工作台要把交付流程产品化，避免所有事情都依赖微信群、人工表格和个人经验。

## 2. 客户健康度

建议评分维度：

| 维度 | 说明 |
|---|---|
| 配置完成度 | 品牌、产品、码、页面、活动、私域是否配置完整 |
| 上线活跃度 | 最近 30 天是否有发布、活动、扫码 |
| 扫码表现 | 扫码量、扫码人数、增长趋势 |
| 转化表现 | 领券、留资、加微、跳转、核销 |
| 风险状态 | 是否有大量异常扫码、码未激活、活动过期 |
| 商业状态 | 套餐到期、码量不足、扫码量不足、服务包消耗 |

## 3. 代运营任务模板

### 首次上线任务

```text
客户资料确认
→ 产品资料入库
→ 证书/报告上传
→ 行业模板选择
→ H5 页面配置
→ 权益活动配置
→ 私域路径配置
→ 码策略确定
→ 码包生成/既有码接管
→ 上线检查
→ 客户确认
→ 发布
```

### 日常运营任务

- 新产品上线。
- 新批次检测报告更新。
- 节日促销活动配置。
- 优惠券库存补充。
- 私域入口调整。
- 活动到期页面切换。
- 异常扫码排查。
- 月度数据复盘。

## 4. 复盘报告结构

```text
1. 本期概览
2. 扫码趋势
3. 产品/批次表现
4. 渠道/区域表现
5. 活动转化漏斗
6. 私域与商城跳转
7. 异常扫码和防窜线索
8. 用户画像
9. 问题诊断
10. 下期建议
```

## 5. 常用优化动作

| 问题 | 优化动作 |
|---|---|
| 扫码率低 | 优化包装引导语、加大权益吸引力、改变二维码位置 |
| 页面跳出高 | 首屏突出利益点，减少长文，提升加载速度 |
| 领券率低 | 改首扫礼、设置限时、降低领取门槛 |
| 加微率低 | 用专属福利/售后服务/产地直供群引导 |
| 商城跳转低 | 商品卡更清晰，优惠券与购买按钮强关联 |
| 留资率低 | 减少字段，明确用途和福利 |
| 异常扫码多 | 检查码是否被复制、是否存在渠道窜货 |
