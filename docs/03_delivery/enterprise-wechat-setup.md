# 企业微信添加客户能力配置说明

## 适用场景

品牌方希望消费者扫码后添加企业微信，用于复购提醒、客服承接、活动权益发放或私域运营。

## 配置流程

1. 在管理后台进入 `集成管理 > 企业微信`。
2. 填写企业微信的 `企业 ID` 和 `客户联系 Secret`。
3. 复制页面展示的 `后台配置地址`、`Token` 和 `EncodingAESKey`。
4. 在企业微信后台的客户联系接收设置中粘贴以上三项内容。
5. 回到平台点击 `检测连接`，确认状态显示为 `企业微信已连接`。
6. 在活动管理中选择 `引导添加企业微信` 或 `加企微后领取`。

## 活动模式

| 模式 | 消费者体验 | 发放规则 |
| --- | --- | --- |
| 引导添加企业微信 | 消费者可先领取权益，也能看到添加企业微信入口 | 不把添加企业微信作为发放门槛 |
| 加企微后领取 | 消费者领取时会先看到企业微信添加入口 | 平台收到企业微信添加确认后才发放权益 |

## 运营注意事项

- `加企微后领取` 需要企业微信连接正常，否则活动不能上线。
- 企业微信添加确认可能有几秒延迟，消费者可以在添加后点击 `我已添加，继续领取`。
- 如果客户已删除企业微信联系人关系，平台会记录删除事件；当前阶段不自动撤销已领取权益。
- 活动数据中会展示企微添加人数，便于观察添加转化和领取效果。
