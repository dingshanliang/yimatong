# Triage 标签

工程 skills 使用五个固定角色。Beads 中使用同名标签：

| Skill 角色 | Beads 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已充分定义，可由 agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工处理 |
| `wontfix` | `wontfix` | 不计划处理 |

当 skill 提到某个 triage 角色时，使用表中对应的 Beads 标签。
