# 销售拜访话术

## 1. 开场白

```text
我们不是来给您做一个二维码，也不是单纯做溯源。我们想帮您把已经印在包装上的二维码，变成能带来消费者、私域、复购和渠道数据的增长入口。
```

## 2. 需求引导问题

### 包装与扫码

- 现在包装上有没有二维码？
- 消费者扫完后看到什么？
- 这个页面能不能领券、加企微、跳商城？
- 扫码数据现在谁能看到？
- 不同产品、批次、渠道的扫码能区分吗？

### 复购与私域

- 现在消费者买完之后，企业还能再触达他吗？
- 有没有企业微信、公众号、小程序、商城？
- 复购券是怎么发的？
- 私域用户来自哪个产品、哪个渠道，能看出来吗？

### 溯源与信任

- 消费者最关心产地、检测报告、资质还是品牌故事？
- 检测报告是否经常更新？
- 是否需要展示批次、生产日期、证书？

### 渠道与防窜

- 是否有经销商、区域代理、门店？
- 有没有窜货问题？
- 能否知道某一批货原本发往哪里，实际在哪里被扫？

### 落地方式

- 包装是已经印好了，还是下一批要重新印？
- 是否可以先贴码试点？
- 是否有合作印刷厂、标签厂、喷码设备？

## 3. 核心价值话术

### 对老板

```text
您原来的包装码只是一个成本。一码通做的是让它变成增长入口：扫码能领券、能加企微、能跳商城、能沉淀用户，还能看到哪个产品、哪个区域、哪个渠道效果最好。
```

### 对市场/运营

```text
我们提供的是可配置的扫码页和活动中心。您不用重新开发系统，就可以给不同产品、不同批次、不同渠道配置不同活动，并看到转化漏斗。
```

### 对渠道负责人

```text
每个码段可以绑定经销商和区域。系统能看到实际扫码地区，如果大量扫码出现在非授权区域，就可以作为疑似窜货线索。
```

### 对区域品牌/协会

```text
区域品牌可以统一管理成员企业、授权产品、页面模板和品牌背书，同时保留每个企业自己的经营数据和活动能力。
```

## 4. 异议处理

### “二维码不是很普通吗？”

二维码本身普通，但一码通做的不是生成二维码，而是管理二维码背后的产品身份、页面内容、权益活动、用户行为和渠道数据。

### “扫码率会不会很低？”

扫码率取决于包装位置、引导文案和权益设计。我们会建议用“扫码领专属复购券”“扫码查产地报告”“扫码进产地直供群”等明确动机提升扫码率。

### “能不能防伪？”

普通二维码不能绝对防伪。一码通提供轻量验真：一物一码、首扫提示、重复扫码、多地扫码和异常预警。高价值产品建议外码 + 内码或结合物理防伪标签。

### “我们已经有小程序/商城了，还需要吗？”

需要。小程序和商城是交易或会员阵地，一码通是包装入口。它负责把买过产品的人从包装带回小程序、商城或企微，并记录产品、批次、渠道来源。

### “我们已有溯源系统了，还需要吗？”

如果已有溯源系统，一码通可以接管扫码后的营销转化层。原系统提供追溯数据，一码通提供 H5 页面、权益、私域、用户画像和归因。

### “我们不会配置后台怎么办？”

一码通采用 SaaS + 代运营。首轮页面、活动、码包、印刷对接都可以由我们帮您配置，后续也可以继续代运营。
