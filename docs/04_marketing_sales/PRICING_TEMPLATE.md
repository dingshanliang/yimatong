# 报价方案模板

> 本文件为报价结构模板，具体价格需结合客户规模、码量、扫码量、服务内容和集成复杂度确认。

## 1. 单企业品牌方报价结构

```text
基础 SaaS 年费
+ 码量包
+ 扫码量包
+ 高级模块
+ 代配置/代运营服务包
+ 外部系统集成费（如有）
```

## 2. 套餐示例

| 套餐 | 适合客户 | 包含能力 |
|---|---|---|
| 试用版 | 单品试点 | 1-3 个产品、少量码、基础页面、基础统计 |
| 入门版 | 小品牌 | 产品资料、轻量溯源、批次码/少量一物一码、H5 模板、基础活动 |
| 标准版 | 成长期品牌 | 一物一码、优惠券、私域承接、留资、经营看板、数据导出 |
| 专业版 | 多渠道品牌 | 防伪防窜、会员积分、渠道归因、活动风控、外部券码池 |
| 旗舰版 | 大客户 | 自有域名、白标、高级 API、专属支持、外部系统对接 |

## 3. 区域品牌/协会报价结构

```text
区域品牌平台年费
+ 成员企业数
+ 授权产品数
+ 码量/扫码量
+ 区域品牌看板
+ 白标/自有域名
+ 成员企业代运营服务包
```

## 4. 增值服务报价项

| 服务 | 内容 |
|---|---|
| 首次上线服务 | 资料整理、页面配置、首个活动、码包生成、上线检查 |
| 活动运营服务 | 活动策划、页面调整、权益配置、复盘报告 |
| 码落地服务 | 标签文件、可变印刷、喷码/贴标对接支持 |
| 行业模板服务 | 茶叶、大米、水果、礼盒、区域品牌模板 |
| 集成服务 | 商城、CRM、ERP、旧溯源系统、GTS/食链通对接 |
| 培训服务 | 管理员培训、运营培训、经销商/门店培训 |

## 5. 报价注意事项

- 明确码量和扫码量超额规则。
- 明确代运营服务次数和响应范围。
- 明确是否包含印刷/标签实际成本。
- 明确外部平台接口权限由客户或平台提供。
- 明确现金红包、支付、税务、财务结算不在标准版范围。
