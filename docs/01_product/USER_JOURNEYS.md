# 用户旅程与核心流程

## 1. 消费者扫码旅程

```text
看到包装二维码
→ 使用微信/相机/支付宝扫码
→ 打开 H5 页面
→ 系统校验码状态
→ 展示产品信任信息
→ 首扫/重扫/异常提示
→ 领取权益或查看溯源
→ 授权手机号/微信/表单（按场景）
→ 加企微/关注公众号/跳小程序/跳电商店铺
→ 后续复购或被私域承接
```

关键原则：

- 看溯源低门槛，不强制登录。
- 领权益有授权，有规则，有风控。
- 扫码后必须有明确的下一步动作：领券、加微、购买、留资或查看报告。
- 码异常时不直接恐吓消费者，要给出清晰解释和客服路径。

## 2. 品牌方首次上线旅程

```text
销售开通租户
→ 品牌方填写基础信息
→ 上传产品/证书/检测报告/素材
→ 选择行业模板
→ 配置首个扫码页
→ 配置权益和私域路径
→ 选择码策略：批次码/一物一码/双码
→ 生成或接管二维码
→ 导出码包或配置旧码接管
→ 印刷/贴标/喷码对接
→ 激活码段
→ 预览、发布
→ 数据看板复盘
```

## 3. 代运营交付旅程

```text
建立客户档案
→ 收集资料清单
→ AI/人工整理资料
→ 建立产品资料库
→ 配置扫码页草稿
→ 配置活动和权益
→ 配置私域承接
→ 制定码落地方案
→ 客户确认
→ 发布上线
→ 监控扫码与异常
→ 7/14/30 天复盘
→ 建议二次活动或增购服务
```

## 4. 码生产落地流程

### 4.1 标签贴码

```text
后台生成码批次
→ 导出标签文件
→ 标签供应商或标签打印机打印
→ 人工/贴标机贴到包装
→ 平台标记已交付/待激活
→ 品牌方激活码段
→ 消费者扫码
```

适合小批量、试点、旧包装库存、农产品企业、礼盒。

### 4.2 可变数据印刷

```text
后台生成码包
→ 导出印刷数据包
→ 印刷厂导入可变数据印刷系统
→ 每个包装印不同二维码
→ 回传印刷批次和码段
→ 品牌方激活
→ 消费者扫码
```

适合稳定 SKU、大批量包装袋、长期销售产品。

### 4.3 产线喷码/赋码

```text
后台生成码池
→ 产线设备通过文件/API 获取码
→ 每生产一件喷印一个码
→ 设备回传使用状态
→ 绑定生产批次/时间/产线
→ 激活或自动激活
```

适合中大型工厂、高速产线、瓶装/盒装/袋装产品。

## 5. 既有码接管流程

```text
盘点旧码类型
→ 判断是否可接管域名
→ 可接管：CNAME/域名解析到一码通
→ 不可接管：原系统中转跳转或重新贴码
→ 批量导入旧码编号、产品、批次、渠道
→ 配置新 H5 页面和活动
→ 上线灰度验证
→ 数据看板复盘
```

## 6. 区域品牌/协会旅程

```text
区域品牌总账号开通
→ 配置区域品牌 Logo/域名/白标
→ 创建成员企业
→ 配置统一页面模板
→ 配置授权产品规则
→ 成员企业导入产品和批次
→ 统一生成/接管包装码
→ 消费者扫码看到区域品牌背书 + 企业产品信息
→ 区域方查看汇总看板
```

## 7. 经销商/门店/导购旅程

```text
品牌方创建渠道组织
→ 分配码段/推广码
→ 经销商或门店获得轻量入口
→ 查看自己区域扫码、留资、核销数据
→ 导购推广专属码
→ 系统统计扫码、留资、加微、核销、成交导入
→ 生成激励结算依据
```
