# 一码通信息架构

## 1. 总体结构

```text
一码通 SaaS
├─ 平台管理
│  ├─ 租户管理
│  ├─ 套餐与额度
│  ├─ 服务商/代运营管理
│  ├─ 客户健康度
│  └─ 系统配置
├─ 客户工作台
│  ├─ 经营看板
│  ├─ 初始化向导
│  ├─ 品牌资料
│  ├─ 产品资料库
│  ├─ 码管理
│  ├─ 扫码页
│  ├─ 活动中心
│  ├─ 权益中心
│  ├─ 会员与积分
│  ├─ 私域承接
│  ├─ 渠道与经销商
│  ├─ 数据分析
│  ├─ 风控预警
│  ├─ 集成中心
│  └─ 设置
├─ 区域品牌/协会工作台
│  ├─ 成员企业
│  ├─ 授权产品
│  ├─ 统一模板
│  ├─ 统一码规则
│  ├─ 区域品牌看板
│  └─ 汇总数据
├─ 轻量协作入口
│  ├─ 经销商入口
│  ├─ 门店/导购入口
│  └─ 印刷/标签协作入口
└─ 消费者 H5
   ├─ 产品信任页
   ├─ 验真结果页
   ├─ 权益领取页
   ├─ 积分/会员页
   ├─ 留资表单页
   ├─ 私域跳转页
   ├─ 活动规则页
   └─ 隐私授权页
```

## 2. 后台一级导航

| 一级导航 | 说明 |
|---|---|
| 首页看板 | 经营指标、活动转化、异常预警、客户待办 |
| 品牌资料 | 品牌信息、联系方式、域名、白标配置 |
| 产品资料库 | 产品、SKU、批次、产地、检测报告、证书、素材 |
| 码管理 | 码批次、码段、码包、导出、印刷/贴标/喷码、激活、作废 |
| 扫码页 | 页面模板、行业模板、模块配置、版本、发布、下线 |
| 活动中心 | 活动规则、时间、渠道、预算、权益、风控 |
| 权益中心 | 优惠券、积分、礼品、抽奖、外部权益连接器 |
| 私域承接 | 企微、公众号、小程序、电商店铺、表单、客服入口 |
| 渠道管理 | 经销商、区域、门店、导购、团长、推广码 |
| 数据分析 | 经营看板、活动看板、渠道风控看板、区域品牌看板 |
| 风控预警 | 重复扫码、多地扫码、窜货、刷码、异常领券 |
| 集成中心 | 外部券、商城、CRM、ERP、GTS/食链通、Webhook/API |
| 代运营工作台 | 资料收集、页面配置、上线检查、复盘、客户健康度 |
| 系统设置 | 账号、权限、套餐、通知、合规、日志 |

## 3. 消费者页面信息架构

```text
扫码入口
├─ 解析与校验
│  ├─ 码是否存在
│  ├─ 码是否激活
│  ├─ 是否作废/冻结
│  ├─ 首扫/重扫状态
│  └─ 活动状态
├─ H5 首页
│  ├─ 产品与品牌
│  ├─ 验真提示
│  ├─ 核心权益
│  ├─ 轻量溯源
│  ├─ 检测/资质
│  ├─ 私域/购买入口
│  └─ 活动规则
└─ 行为动作
   ├─ 领券
   ├─ 积分
   ├─ 抽奖
   ├─ 留资
   ├─ 加企微
   ├─ 关注公众号
   ├─ 跳小程序
   ├─ 跳电商店铺
   └─ 查看隐私/撤回授权
```

## 4. 模块化 H5 页面组件

| 组件 | 用途 | 是否首版必备 |
|---|---|---|
| 品牌头图 | 建立品牌识别 | 是 |
| 产品卡片 | 展示产品名称、规格、批次 | 是 |
| 验真状态 | 首扫/重扫/异常提示 | 是 |
| 轻量溯源 | 产地、批次、生产日期、保质期 | 是 |
| 检测报告 | 展示报告摘要、图片、附件 | 是 |
| 资质证书 | 企业证书、地理标志、认证 | 是 |
| 视频/图文故事 | 品牌和产品内容 | 是 |
| 优惠券 | 平台券/外部券/券码池 | 是 |
| 积分 | 积分账户和兑换入口 | 第二阶段 |
| 留资表单 | 手机、地区、意向 | 是 |
| 企微入口 | 加客服、进群、导购 | 是 |
| 公众号入口 | 关注、内容承接 | 是 |
| 小程序入口 | 跳品牌小程序或商城 | 是 |
| 电商入口 | 淘宝、京东、抖店、有赞、微盟等 | 是 |
| 活动规则 | 参与条件、权益、限制 | 是 |
| 隐私授权 | 用户协议、隐私政策、授权记录 | 是 |
| 异常客服 | 码异常时联系品牌方 | 是 |
