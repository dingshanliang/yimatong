# 轻量验真状态模型

状态：产品决策已确认  
确认日期：2026-07-26

## 1. 产品承诺

一码通提供“平台签发状态核验、首次与重复验证记录、异常使用风险提示”，不承诺普通二维码能够证明眼前实物绝对为正品。

消费者结果必须区分：

- 平台能够证明的码和生产批次事实；
- 系统根据扫码行为形成的风险判断；
- 运营人员调查后作出的人工处置结论。

## 2. 码生命周期

码级生命周期只有四个互斥状态：

| 状态   | 含义                           | 可恢复 | 消费者溯源         | 营销权益   |
| ------ | ------------------------------ | ------ | ------------------ | ---------- |
| 未激活 | 已由平台签发，但品牌方尚未启用 | 可激活 | 不展示完整溯源     | 阻断       |
| 有效   | 已启用并可正常验证             | —      | 展示               | 按活动规则 |
| 冻结   | 因调查或风险控制临时停用       | 是     | 展示并提示正在核查 | 暂停       |
| 作废   | 永久终止使用                   | 否     | 不提供正常验真结果 | 阻断       |

以下内容不属于码生命周期：

- 已生成、已导出、印刷中、已交付：码批次或印刷交付进度；
- 首次验证、重复验证：扫码事件；
- 高频、多地、疑似复制：风险信号；
- 查无此码：查询结果。

## 3. 首次验证与首次参与

### 首次验证

- 按码全局计算；
- 一枚有效码只能发生一次；
- 不因消费者、设备、活动或浏览器变化而重置；
- 表示“这是平台首次记录到该码的消费者验证”，不表示“平台确认实物为正品”。

### 首次参与

- 按活动规则和消费者身份计算；
- 用于新人权益、首次领取等营销资格；
- 不改变该码是否已经首次验证。

验真事实与营销资格不得共用同一个字段或状态。

## 4. 消费者结果矩阵

| 场景                   | 消费者结果                                                                   | 溯源内容                     | 权益       | 后台动作                   |
| ---------------------- | ---------------------------------------------------------------------------- | ---------------------------- | ---------- | -------------------------- |
| 查无此码               | 未查询到有效码信息，请检查二维码或联系品牌方                                 | 不展示，不泄露产品或租户信息 | 阻断       | 记录无效查询和受控风险信号 |
| 未激活码               | 该码尚未启用，请核对购买渠道或联系品牌方                                     | 不展示完整溯源               | 阻断       | 形成未激活码提前流出记录   |
| 有效，首次验证         | 这是本系统记录的首次验证                                                     | 展示权威产品和生产批次       | 按活动规则 | 写入首次验证事件           |
| 有效，正常重复验证     | 该码此前已有验证记录；展示首次验证时间和累计次数；说明重复查询本身不代表异常 | 展示                         | 按活动规则 | 写入重复验证事件           |
| 有效，存在异常使用信号 | 该码存在异常使用记录，建议核对购买渠道或联系品牌方                           | 继续展示                     | 暂停       | 生成风险记录并进入人工调查 |
| 冻结                   | 该码正在核查，请联系品牌方                                                   | 继续展示                     | 暂停       | 保留冻结原因、操作人和时间 |
| 作废                   | 该码已失效，请联系品牌方                                                     | 不提供正常验真结果           | 阻断       | 保留不可变的作废审计记录   |

消费者端不得展示其他扫码者的位置、设备、IP 或身份。

消费者端不得使用：

- “首次扫码，确定为正品”
- “官方绝对防伪”
- “重复扫码，所以是假货”
- “系统已确认复制码”

## 5. 异常使用规则

高频、多地或其他异常使用特征只形成风险信号：

- 不自动改变码的生命周期；
- 不自动判定假货；
- 不自动永久冻结或作废；
- 消费者仍可查看真实溯源内容；
- 可套利的优惠券、积分等奖励暂停；
- 后台进入人工调查。

风险规则必须记录命中的事实、证据质量、规则版本和风险等级。

## 6. 运营后台

码详情分三层展示：

### 平台事实

- 当前码生命周期；
- 产品、SKU 和权威生产批次；
- 首次验证时间和累计次数；
- 扫码事件。

消费者展示的批次信息必须直接来自权威生产批次，不允许页面模板维护另一份可冲突的批次值。

### 风险判断

- 命中的规则；
- 证据来源和质量；
- 风险等级；
- 当前权益处置。

风险判断必须明确标识为系统推断，不得呈现为假货或窜货结论。

### 人工处置结论

- 调查结果；
- 处理动作；
- 原因和说明；
- 操作人和时间。

## 7. 权限

- 品牌管理员和被明确授权的风控运营可以冻结、解除冻结；
- 代运营获得该租户明确授权后可以冻结，不能默认跨客户操作；
- 作废默认只有品牌管理员可以执行；
- 作废必须填写原因并二次确认；
- 平台管理员不能静默代替品牌方作废，只能通过有完整审计记录的支持流程介入。

## 8. 规格与验收约束

后续规格必须验证：

1. 同一码只有第一条有效消费者验证被标记为首次验证。
2. 不同消费者的首次参与资格不会改写码的首次验证事实。
3. 消费者批次展示与后台生产批次完全一致。
4. 正常重复验证只显示首次时间和累计次数，不泄露其他扫码者信息。
5. 异常使用信号暂停权益，但不自动冻结、作废或判假。
6. 冻结可恢复，作废不可恢复。
7. 未激活码与查无此码的消费者结果和后台动作不同。
8. 运营后台可分别审计平台事实、风险判断和人工处置结论。
9. 未授权角色不能冻结、解除冻结或作废。
