# 一码通产品路线图

## 1. 路线图原则

一码通采用“完整规划、分阶段研发”的路线。产品边界必须完整覆盖 SaaS、码管理、H5、轻量溯源、营销权益、私域承接、防伪防窜、数据归因、区域品牌、代运营和外部集成；研发实施按阶段推进，避免一次性上线过大。

## 2. 三阶段路线

### 阶段一：核心闭环

目标：完成“开通客户 → 配资料 → 生成/接管码 → 配页面 → 扫码 → 领券/留资/私域跳转 → 数据统计”的闭环。

范围：

- 多租户 SaaS、基础权限、套餐额度。
- 品牌、产品、SKU、批次、检测报告、证书。
- 码批次、码包、码状态、批次码、一物一码。
- 既有码接管基础能力。
- H5 模块化模板、行业模板、页面版本。
- 私域承接：企微、公众号、小程序、电商店铺、留资表单。
- 优惠券/权益基础配置。
- 基础经营看板与活动看板。
- 数据导出。
- 代运营工作台基础版。

### 阶段二：增强闭环

目标：增强“轻量验真、防窜货、会员积分、活动风控、数据归因”。

范围：

- 外码/内码双码。
- 首扫、重扫、多地扫码、疑似复制码预警。
- 经销商、区域、门店流向绑定。
- 码段分配与跨区扫码预警。
- 轻量会员、积分账户、积分规则、积分兑换权益。
- 活动风控规则引擎。
- 渠道风控看板。
- 区域品牌/协会基础版。
- 外部成交数据手动导入与 GMV 归因。
- 短信/订阅消息关键通知。

### 阶段三：规模化能力

目标：形成可规模化销售、服务商交付、行业模板复制和大客户集成能力。

范围：

- AI 资料识别、页面文案、活动方案生成。
- 外部权益连接器 L2-L4：券码池、API 发券、订单回流。
- Webhook / Open API。
- CRM、会员系统、ERP、进销存、旧溯源系统对接。
- 区域品牌高级管理：统一模板、统一码规则、成员企业汇总看板。
- 客户自有域名、白标、高级多语言。
- 现金红包插件或大客户定制能力。
- 专属租户 / 私有化部署预案。

## 3. 优先级分层

| 层级 | 判断标准 | 示例 |
|---|---|---|
| P0 | 没有它无法形成扫码增长闭环 | 租户、产品资料、码生成、H5、私域跳转、基础看板 |
| P1 | 直接增强转化、风控或交付效率 | 会员积分、轻量防窜、代运营任务流、外部券码池 |
| P2 | 提升规模化和自动化 | AI、Open API、CRM/ERP 集成、区域品牌高级能力 |
| P3 | 高复杂度或高合规风险 | 现金红包、私有化、复杂反作弊模型 |

## 4. 里程碑

| 里程碑 | 输出物 | 验收标准 |
|---|---|---|
| M1 产品原型 | 后台 IA、H5 模板、码生命周期流程 | 能评审完整用户闭环 |
| M2 核心功能开发 | SaaS 底座、码管理、页面、活动 | 内部演示扫码闭环 |
| M3 试点客户上线 | 1-3 个食品/农产品客户 | 实际包装码可扫，产生转化数据 |
| M4 代运营流程成型 | 资料收集、配置、上线、复盘模板 | 交付不依赖单个专家 |
| M5 标准版发布 | 套餐、报价、营销材料、销售话术 | 可对外标准销售 |
| M6 行业模板复制 | 食品/农产品/礼盒/区域品牌模板 | 新客户上线时长显著缩短 |

## 5. 阶段一的建议开发 Epic

1. 租户与权限
2. 客户开通与套餐额度
3. 产品、SKU、批次、素材库
4. 码批次、码包、码状态
5. 二维码解析服务
6. H5 页面引擎
7. 活动与权益基础配置
8. 私域/外部链接承接
9. 埋点与基础看板
10. 数据导出
11. 代运营工作台基础版
12. 上线检查与操作日志
