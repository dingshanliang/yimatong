# 商业模式与计费方案

## 1. 商业模式

一码通采用 SaaS 订阅 + 码量/扫码量 + 增值服务的组合收费。不能只按二维码数量收费，否则容易被客户理解为二维码工具。收费锚点应围绕包装数字化入口、消费者资产、营销活动、复购归因和渠道数据。

## 2. 单企业版本

| 版本 | 适合客户 | 核心权益 | 收费组成 |
|---|---|---|---|
| 试用版 | 销售线索、试点客户 | 少量产品、少量码、基础模板 | 免费/限时 |
| 入门版 | 小品牌、小农企 | 产品资料、批次码/少量一物一码、H5 模板、基础统计 | 年费 + 码量 |
| 标准版 | 成长期食品/农产品品牌 | 一物一码、活动中心、优惠券、私域承接、经营看板 | 年费 + 码量/扫码量 |
| 专业版 | 多产品、多渠道品牌 | 防伪防窜、积分、渠道归因、外部权益连接器 | 年费 + 高级模块 + 服务包 |
| 旗舰版 | 大客户/集团 | 自有域名、白标、高级 API、专属支持 | 年费 + 定制集成 + 服务费 |

## 3. 区域品牌/协会版本

计费维度：

- 区域品牌平台年费。
- 成员企业数量。
- 授权产品数量。
- 码量与扫码量。
- 区域品牌看板。
- 统一模板、统一码规则、白标域名。
- 代运营与培训服务包。

推荐包装：

| 版本 | 适合场景 | 收费逻辑 |
|---|---|---|
| 区域基础版 | 单一区域品牌，少量成员企业 | 平台年费 + 成员企业数 + 码量 |
| 区域标准版 | 多品类、多企业 | 平台年费 + 授权产品数 + 区域看板 |
| 区域旗舰版 | 政府/协会/园区项目 | 平台年费 + 白标 + 数据大屏 + 代运营服务 |

## 4. 增值服务

| 服务包 | 内容 | 计费方式 |
|---|---|---|
| 首次上线包 | 资料整理、页面配置、首个活动、码包生成 | 一次性服务费 |
| 活动运营包 | 活动策划、权益配置、页面调整、数据复盘 | 月费/次费 |
| 印刷对接包 | 标签文件、可变印刷、喷码对接、贴标建议 | 项目服务费 |
| 行业模板包 | 茶叶、大米、水果、调味品、预制菜、礼盒 | 按模板/行业收取 |
| 集成服务包 | 商城、CRM、ERP、旧溯源系统对接 | 项目制 |
| 区域品牌运营包 | 成员企业培训、资料收集、统一模板、汇总报告 | 月费/年费 |

## 5. 计费指标

| 指标 | 定义 | 用途 |
|---|---|---|
| 码量 | 生成或接管的二维码数量 | 成本和规模度量 |
| 扫码量 | 消费者访问次数 | 流量与服务消耗 |
| 活动数 | 同时运行或累计活动数量 | 功能分级 |
| 产品数 | 产品/SKU/批次数量 | 套餐限制 |
| 成员企业数 | 区域品牌下挂企业数量 | 区域版本计费 |
| 高级看板 | 风控、区域、渠道、GMV 归因 | 高级模块 |
| 外部集成数 | 对接外部系统数量 | 集成收费 |

## 6. 报价原则

- 不把基础年费压得过低，否则难以支持代运营服务。
- 码量包适合表达规模，但不是唯一收费锚点。
- 扫码量包用于控制系统成本，但客户沟通时要强调“数字流量”。
- 高级能力按价值收费：防窜、区域品牌、外部集成、白标、AI、数据回流。
- 代运营服务必须单独报价，不应无偿包含在低价 SaaS 中。
